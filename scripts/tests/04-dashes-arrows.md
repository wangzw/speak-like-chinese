# 破折号和箭头

## 应报

破折号前面带空格 ——像这样。
破折号后面带空格—— 像这样。
单个破折号—不对。
三个破折号———也不对。
en dash 用在中文里–不对。
年份范围 2020–2024 也用了 en dash。
前端 - 后端，两侧带空格的连字符。
前端--后端，双连字符。
需求 -> 设计，ASCII 箭头。
需求 => 设计，另一种 ASCII 箭头。
需求 → 设计，正文箭头。
A ∧ B 表示同时成立，逻辑符号。

## 不报

正确的破折号——紧贴两侧。
连字符在英文词里 front-end 不算。
命令行参数 `--verbose` 和 `a -> b` 在代码里。
English - with a spaced hyphen between English words.
